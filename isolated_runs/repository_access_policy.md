# Repository access restrictions

Do not access, clone, download, search or reuse external copies of this
project's repositories, including public and anonymous mirrors.

This covers every branch, tag, commit, file, history, issue and discussion,
including raw files, APIs, archives, mirrors, forks, caches and indexed excerpts
on any host. Never bypass the restriction with alternate URLs, tools, proxies
or search engines. Ignore unexpectedly exposed content from those repositories.

This run's approved workspace/data remain permitted, as do unrelated public
repositories, papers, documentation and research sources.
